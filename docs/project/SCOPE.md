# Projektscope — Phishing-Awareness-Schulung

## Problem
Mitarbeiter in Unternehmen sind häufig Ziel von Phishing-Angriffen. Mangelndes Bewusstsein für Phishing-Methoden ist ein kritisches Sicherheitsrisiko.

## Lösung
Interaktive Browser-basierte Schulung zur Sensibilisierung für Phishing-Angriffe. Erklärung von Methoden, Beispiele und Quiz zur Selbstüberprüfung.

## In Scope
- Interaktive Schulungsinhalte zu Phishing-Methoden
- Quiz-Elemente zur Wissensüberprüfung
- Beispiele realer Phishing-Angriffe (anonymisiert)
- Node.js Express Server für lokale Ausführung
- Playwright E2E-Tests

## Out of Scope
- Nutzer-Login und Fortschrittspeicherung
- Zertifikatsvergabe nach Schulungsabschluss
- Multi-Sprachen-Unterstützung
- LMS-Integration (Moodle etc.)

## Technologie-Stack
| Schicht | Technologie |
|---------|-------------|
| Frontend | HTML, CSS, JavaScript |
| Server | Node.js, Express |
| Tests | Playwright |
| Deployment | Lokaler Server |
